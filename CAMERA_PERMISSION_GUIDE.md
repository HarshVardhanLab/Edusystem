# 📷 Camera Permission Guide for QR Scanning

## Why Camera Fails

Browsers require **HTTPS** or **localhost** for camera access due to security reasons. Additionally, you need to grant camera permission.

## ✅ How to Enable Camera Access

### For Chrome:
1. Click the **camera icon** (🎥) in the address bar (left side)
2. Select **"Allow"** for camera access
3. Click **"Done"**
4. **Refresh the page** (F5 or Ctrl+R)
5. Try scanning again

### For Firefox:
1. Click the **camera icon** in the address bar
2. Select **"Allow"** from the dropdown
3. **Refresh the page**
4. Try scanning again

### For Safari:
1. Go to **Safari > Settings for This Website**
2. Find **Camera** permission
3. Select **"Allow"**
4. **Refresh the page**
5. Try scanning again

### For Edge:
1. Click the **lock icon** in the address bar
2. Click **"Permissions for this site"**
3. Find **Camera** and select **"Allow"**
4. **Refresh the page**
5. Try scanning again

## 🔧 Troubleshooting

### Issue 1: "Permission Denied"
**Solution:**
- Clear browser cache and cookies
- Check browser settings: Settings > Privacy > Camera
- Make sure no other app is using the camera
- Try a different browser

### Issue 2: "Camera Already in Use"
**Solution:**
- Close Zoom, Skype, Teams, or other video apps
- Close other browser tabs using camera
- Restart your browser
- Restart your computer if needed

### Issue 3: "No Camera Found"
**Solution:**
- Check if your device has a camera
- For laptops: Make sure camera is not disabled in BIOS
- For external cameras: Check USB connection
- Try a different device (phone/tablet)

### Issue 4: "Not Secure Context"
**Solution:**
- Make sure you're accessing via `localhost` or `https://`
- If using IP address, camera won't work (use localhost instead)
- Ask admin to set up HTTPS

## 📱 Best Practices

### For Desktop/Laptop:
1. Use **Chrome** or **Firefox** (best support)
2. Access via **localhost** (not 127.0.0.1 or IP)
3. Grant camera permission when prompted
4. Keep browser updated

### For Mobile:
1. Use **Chrome** or **Safari**
2. Grant camera permission in browser settings
3. Make sure camera is not being used by another app
4. Use rear camera for better scanning

## ✨ Easy Alternative: Manual Entry

**Don't want to deal with camera permissions?**

Use the **"Enter Manually"** option:
1. Click **"Enter Manually"** button
2. Ask admin for the QR code text
3. Copy and paste the code
4. Click **"Mark Attendance"**
5. Done! ✅

**Manual entry is just as fast and always works!**

## 🎯 For Admins

To help students:
1. Generate the QR code
2. Display it on a screen/print it
3. Also share the **code text** via WhatsApp/Email
4. Students can use either camera or manual entry

## 🔐 Security Note

Camera access is restricted by browsers for your security:
- Only works on HTTPS or localhost
- Requires explicit user permission
- Cannot be accessed without user consent
- This is a browser security feature, not a bug

## 📞 Still Having Issues?

If camera still doesn't work:
1. **Use Manual Entry** (recommended, always works)
2. Try a different browser
3. Try a different device
4. Contact your library admin for help
